# 🔍 Googling Like a Pro Cheat Sheet

Enhance your web search efficiency using professional search operators and techniques. 

## 🛠️ Essential Search Operators


| Operator | Syntax | Purpose | Example |
| :--- | :--- | :--- | :--- |
| **Exact Match** | `"keyword"` | Searches for the exact phrase in that precise order | `"software engineer"` |
| **Exclude Term** | `-keyword` | Excludes specific words from your search results | `jaguar -car` |
| **Site Search** | `site:domain.com` | Restricts search results to a specific website | `site:github.com python` |
| **File Type** | `filetype:ext` | Finds specific file extensions like PDFs or Docs | `git cheat sheet filetype:pdf` |
| **Wildcard** | `*` | Acts as a placeholder for any unknown word | `how to * in javascript` |
