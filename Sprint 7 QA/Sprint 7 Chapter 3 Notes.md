# Python Data Structures: List vs Tuple vs Set

| Feature | List | Tuple | Set |
|---|---|---|---|
| Created by using | `[ ]` | `( )` | `{ }` |
| Size | Dynamic | Fixed | Dynamic |
| Indexing | Allowed | Allowed | Not allowed |
| Order | Ordered | Ordered | Unordered |
| Elements | Changeable | Unchangeable | Unchangeable |
| Duplicates | Allowed | Allowed | Not allowed |
| Data types | Multiple data types can be stored at the same time | Multiple data types can be stored at the same time | Multiple data types can be stored at the same time |
