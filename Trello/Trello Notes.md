# Managing Projects with Trello

As mentioned earlier, Trello allows you to represent the tasks in your project as **cards** and organize those cards into piles called **lists**. 

You can create lists for whatever you’d like, but the typical labels are:
* **To Do**
* **Doing**
* **Done**

## 📋 Workflow Example

1. **Creation**: When a card is created, it starts off in the `To Do` list. Cards include all of the information needed to keep track of the task, such as due dates, checklists, labels, and comments. Typically, you’ll add everything to your `To Do` list and go from there.
2. **Planning**: For example, when working on a project from TripleTen, you will start off by reading the project description and breaking the project down into individual tasks. Each task will get added to your `To Do` list with the deadlines and any other important information.
3. **Execution**: Once you know all of the tasks you need to do and their deadlines, you can start working on them. When you start a task, move it to the `Doing` list.
4. **Completion**: Completed tasks are moved to your `Done` list. Apart from making you feel good about your accomplishments, this allows you to track your overall progress and plan your time accordingly.

### 📌 Keyboard Shortcuts

Trello has several keyboard shortcuts that can help you work more efficiently. Here are some of the most useful ones:


| Key | Action |
| :---: | :--- |
| <kbd>n</kbd> | Create a new card |
| <kbd>b</kbd> | Open the "boards" menu |
| <kbd>f</kbd> | Search for cards or boards |
| <kbd>c</kbd> | Create a new checklist |
| <kbd>t</kbd> | Add a label to a card |
| <kbd>d</kbd> | Add a due date to a card |
| <kbd>q</kbd> | Quickly edit a card’s title or description |
| <kbd>m</kbd> | Add a member to a card |
| <kbd>s</kbd> | Subscribe to a card or board for updates |
| <kbd>?</kbd> | View the keyboard shortcuts menu |
