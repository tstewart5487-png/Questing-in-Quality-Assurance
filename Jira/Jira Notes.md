# Getting Started with Jira

Creating a project is your very first step when starting with Jira. 

## Project Setup
- [ ] **Definition**: A collection of tasks called issues.
- [ ] **Creation**: Build from scratch or use pre-made templates.
- [ ] **Next Steps**: Invite team members and assign user permissions.

## Issue Management
- **Core Components**: Every issue has an ID, summary, description, and status.
- **Types**: Represents bugs, new features, or standard tasks.
- **Tracking**: Assign to team members and move through workflows.

## Filter Tips
* **My Open Issues**: Shows tasks currently assigned to you.
* **Recently Viewed**: Locates items you looked at standardly.
* **Saved Filters**: Stores custom search criteria for fast access.

## Essential Shortcuts
* <kbd>c</kbd>: Create a new issue.
* <kbd>t</kbd>: Assign an issue to yourself.
* <kbd>e</kbd>: Edit the selected issue.
* <kbd>m</kbd>: Add a comment quickly.
* <kbd>.</kbd>: Open the quick operations menu.
